# 经管论文数据自动处理器

面向经管类问卷论文的数据分析桌面工具。导入 CSV 或 Excel 数据后，可构建量表、配置多条研究路径，并生成可直接用于论文整理的分析结果。

## 主要功能

- 量表构建与反向题处理；
- 验证性因子分析（CFA）；
- 共同方法偏差检验：Harman 降维法与 ULMC；
- 描述性统计与相关分析；
- 多路径主效应、调节、中介与被调节中介分析；
- Bootstrap 中介效应检验、简单斜率、Johnson-Neyman 分析与调节效应图；
- 导出 HTML 分析报告、Excel 结果表、图表、JSON 配置和完整审计包；
- 支持保存和导入分析设置，方便重复使用研究模型。

## 桌面版本

软件可在本机运行，无需浏览器或本地代理服务。

- **macOS Apple Silicon**：提供 `.dmg` 与 `.zip` 桌面版；
- **Windows x64**：提供免安装 `.zip` 和安装版 `-setup.exe`。

请在 [Releases](https://github.com/minglwp/econ-paper-analyzer/releases) 页面下载对应系统的最新版本。
